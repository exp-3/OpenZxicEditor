## 简介

一键解包和打包 zxic 烧录器固件的工具。

附带 MTD 分区的拆分和合并功能。

## 使用方法

### 解包和打包

把烧录器固件拆分为分区文件并解包。

解包后的文件会放在名称以`z.`开头的工程文件夹中。

然后可修改解包的文件，最后重新打包。

## 注意事项

1. 此程序尚不完善，可能存在一些问题，欢迎提出建议。
2. 开发时已留意了空格和中文路径的问题，但如果遇到迷惑 bug 可以尝试将文件放到简单路径下再试。
3. 软件会解包所有受支持的分区类型。如果某分区不需要修改，那么建议删除相应的解包文件夹，合并时将会自动使用原版。
